# Universal Map Annotator

A drop-in annotation toolkit for offline Leaflet maps. Copy it into any folder containing a `*_leaflet.html` map, run the setup script, and start drawing — lines, polygons, rectangles, circles, and markers — directly on your map with full color control, keyboard shortcuts, undo, layer visibility, and GeoJSON save/load.

## Features

| Feature | Details |
|---|---|
| **Drawing Tools** | Polyline, Polygon, Rectangle, Circle, Marker — all with edge snapping |
| **Color Palette** | Pick any color, bulk-import hex palettes, live-swap colors mid-draw |
| **Paint Mode** | Click any existing shape to re-color it instantly |
| **Layer Visibility** | Toggle shape groups on/off by color |
| **Undo** | Full undo stack — Ctrl+Z removes shapes, reverts paint, and deletes last vertex while drawing |
| **Auto-Tagging** | Each shape gets a unique ID tooltip (e.g. `Polygon_1`, `Circle_3`) |
| **GeoJSON Save/Load** | Export all annotations to `.geojson`, reload them later with colors and tags preserved |
| **Keyboard Shortcuts** | Fully customizable hotkeys for every tool |
| **Zero Dependencies** | Everything is bundled — no internet, no npm, no build step |

## Quick Start

1. **Copy** the `Universal Map Annotator` folder into your offline map directory (the one with `*_leaflet.html` files).

2. **Run** `Setup Map Annotator.bat` (double-click it).

3. **Open** your map HTML file in a browser — the annotation toolbar appears automatically.

That's it. The setup script injects the necessary `<script>` and `<link>` tags into your Leaflet HTML files.

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `L` | Polyline tool |
| `P` | Polygon tool |
| `R` | Rectangle tool |
| `C` | Circle tool |
| `M` | Marker tool |
| `B` | Toggle Paint Mode |
| `Ctrl+Z` | Undo (delete last vertex while drawing, or undo last action) |
| `Ctrl` (hold) | Pan the map while a drawing tool is active |

All hotkeys are customizable — edit the `HOTKEYS` object at the top of `assets/omm-annotator.js`.

## How It Works

The setup script (`setup.ps1`) finds every `*_leaflet.html` file in its directory and injects the annotator scripts just before `</body>`. The annotator waits for the Leaflet `map` variable to be available, then initializes a drawing toolbar, color palette panel, and all event handlers.

Annotations are stored as standard GeoJSON with extra properties (`color`, `tagId`, `isCircle`, `radius`) so everything round-trips cleanly through save/load.

## GeoJSON Format

Exported files follow the GeoJSON spec with these additions:

```json
{
  "type": "FeatureCollection",
  "ommColorPalette": ["#ff0000", "#3388ff", "#00ff00"],
  "features": [
    {
      "type": "Feature",
      "properties": {
        "color": "#ff0000",
        "tagId": "Polygon_1"
      },
      "geometry": { "..." }
    }
  ]
}
```

The color palette is saved alongside features so it's restored on load.

## Requirements

- Windows (for the `.bat` setup script)
- Any modern browser
- An offline Leaflet map (files generated by tools like [Offline Map Maker](https://www.allmapsoft.com/omm/))
